Dependency Scanning Requirements

How DepLens discovers direct & sub-dependencies

To calculate accurate Cascading Blast Radius (BR) and Betweenness Centrality (C_B), DepLens requires resolved dependency trees. Without lockfiles or pinned snapshots, transitive dependencies cannot be reconstructed.
PYTHON Freeze Installed Dependencies (pip freeze)

A basic requirements.txt usually specifies only high-level packages. Run pip freeze to snapshot your exact virtual environment with pinned versions:

pip freeze > requirements.txt git add requirements.txt git commit -m "docs: freeze requirements for DepLens deep scan"
🔍 How DepLens links sub-dependencies: DepLens queries the official PyPI Registry API (requires_dist) to determine which sub-dependencies belong to each parent package.
NODE.JS / NPM Commit Your package-lock.json

package.json only lists direct dependencies. package-lock.json contains the entire resolved directed dependency graph and nested version tree:

npm install --package-lock-only git add package-lock.json git commit -m "chore: commit package-lock.json for supply-chain scan"
🔍 How DepLens links sub-dependencies: In package-lock.json, each package entry has a declared dependencies map specifying its exact direct children.
JAVA / MAVEN pom.xml Dependencies

Ensure your pom.xml has standard <dependencies> declared. DepLens parses GroupId, ArtifactId, and version coordinates to build the architecture graph.
