How it works

From repository to risk report in three steps

  1. 1

    Connect GitHub

    Sign in and pick any repository you own or collaborate on, public or private.

  2. 2

    Scan the manifests

    DepLens parses your lockfile or manifest into a directed dependency graph and checks every package for known vulnerabilities.

    package-lock.json requirements.txt pom.xml
  3. 3

    See the blast radius

    Every package gets a composite risk score, a place on the graph and a recommended fix with an effort estimate. Export the table as CSV or PDF.
